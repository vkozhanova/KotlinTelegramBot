# Telegram Bot «English Words B2 Learning Bot»

Telegram-бот для изучения иностранных слов с помощью карточек. Бот показывает слово на изучаемом языке и предлагает выбрать правильный перевод из четырёх вариантов. Прогресс каждого пользователя сохраняется в локальной SQLite-базе данных, а достижения отмечаются поощрительными стикерами.

## Возможности
- Интерактивное изучение слов (оригинал → перевод)
- Персональный прогресс для каждого пользователя (привязка по `chat_id`)
- Статистика: сколько слов выучено, процент изученного
- Сброс прогресса (для текущего пользователя)
- Импорт слов через загрузку текстового файла в чат (формат: `оригинал|перевод`)
- Автоматическое сохранение прогресса в локальной SQLite-базе
- Автоочистка загруженных файлов (через 12 часов)
- Поощрительные стикеры при каждом третьем правильном ответе на слово

## Реализовано
- многопользовательская архитектура (каждый пользователь видит свой прогресс);
- локальная база данных SQLite для хранения слов и прогресса;
- обработка команд и callback-запросов Telegram Bot API;
- динамическое формирование вопросов с выбором из четырёх вариантов;
- инкрементальный счётчик правильных ответов (слово выучивается после 3‑х правильных ответов);
- отправка случайных стикеров при достижении новых рубежей;
- импорт слов из текстового файла (загрузка в чат);
- автоматическая очистка загруженных файлов.
## Архитектура
  Проект построен по принципу разделения ответственности:
- TelegramBotService – инкапсулирует все запросы к Telegram Bot API
- LearnWordsTrainer – бизнес-логика (генерация вопросов, проверка ответов, статистика)
- DatabaseUserDictionary – реализация хранилища данных (SQLite), работа с пользователями и словами
- Основной цикл – опрос обновлений и диспетчеризация событий.
Данные изолированы: слова хранятся в таблице words, прогресс – в таблице user_answers с привязкой к user_id и word_id

## Запуск проекта
1. Клонируйте репозиторий:
```bash
git clone https://github.com/vkozhanova/KotlinTelegramBot.git
cd KotlinTelegramBot
```
2. Создайте файл words.txt (если его нет) в корневой папке. Каждая строка: оригинал|перевод.
```
   cat|кошка
   dog|собака
   house|дом
   apple|яблоко
```
3. Получите токен бота у @BotFather в Telegram.
4. Соберите JAR-файл:
```bash
./gradlew shadowJar
```
5. Запустите бота:
```bash
java -jar build/libs/KotlinTelegramBot-1.0-SNAPSHOT-all.jar
```
При запросе введите токен бота.
Альтернативно передайте токен аргументом:
```bash
java -jar build/libs/KotlinTelegramBot-1.0-SNAPSHOT-all.jar "ВАШ_ТОКЕН"
```
После запуска база данных new_data.db создастся автоматически. Бот начнёт опрашивать обновления, а вы сможете начать обучение, отправив /start.
